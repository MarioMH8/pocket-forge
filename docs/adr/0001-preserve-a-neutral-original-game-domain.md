# Preserve a neutral, original game domain

Pocket Forge must support creature-collection role-playing games without referencing or reproducing protected franchises. The project uses neutral canonical terms such as Creature, Species, Party, Action, Affinity, Recruitment, Transformation, and Dex; official examples, assets, templates, rules, and documentation must be original. The toolkit remains general enough for authors to define their own rules rather than embedding a franchise-derived ruleset.
