# Game Session

Terms specific to the `@pocket-forge/game-session` package.

**Game Session**:
A running simulation of a Game Project from a particular persistent state.
_Avoid_: Playthrough, runtime

**Party**:
The persistent roster of creatures owned by a player in a Game Session. It is not a Combatant Group; combat composition is a combat-local projection.
_Avoid_: Team, combat group
